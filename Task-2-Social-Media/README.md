# Task 2 — Social Media Platform

## CodeAlpha requirements covered
- User profiles
- Posts
- Comments
- Like system
- Follow-ready user model
- Database for users, posts, comments and followers

## Stack
HTML, CSS, JavaScript, Express.js, MongoDB, Mongoose.

## Run
```bash
npm install
cp .env.example .env
npm start
```

On Windows, create `.env` manually using `.env.example`.
