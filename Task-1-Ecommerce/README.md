# Task 1 — Simple E-commerce Store

## CodeAlpha requirements covered
- Product listings
- Shopping cart
- Product details
- Order processing
- Database for products and orders

## Stack
HTML, CSS, JavaScript, Express.js, MongoDB, Mongoose.

## Run
```bash
npm install
cp .env.example .env
npm start
```

On Windows, create `.env` manually using `.env.example`.
Click **Load sample products** once after MongoDB is running.
